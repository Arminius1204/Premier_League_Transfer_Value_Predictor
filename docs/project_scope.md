# Project Scope: Premier League Transfer Intelligence & Player Valuation Engine

## Core Objective
Build an ML-powered football analytics platform that estimates Premier League player transfer value using a large collection of historical football datasets. This is a comprehensive, end-to-end machine learning and football analytics project that integrates multiple data sources to create a unified football intelligence dataset.

## Key Features & Deliverables
The final system will include:

1. **Historical Premier League player statistics**
2. **Historical transfer/transfer-fee data**
3. **Player demographic data**
4. **Club/team data**
5. **Season data**
6. **Match-level or event-level data where useful**
7. **Advanced performance statistics**
8. **Per-90 statistics**
9. **Position-aware features**
10. **Contextual features**
11. **At least 5 ML regression models**
12. **Ensemble valuation**
13. **Explainable AI using SHAP**
14. **Prediction uncertainty/range**
15. **Predicted-vs-actual transfer fee analysis**
16. **Player comparison**
17. **Player similarity**
18. **What-if valuation simulation**
19. **Manchester United analytics/scouting module**
20. **Next.js frontend**
21. **Python ML backend**
22. **Database** (PostgreSQL/Supabase)
23. **Data ingestion and preprocessing pipeline**

## Out of Scope (For Now)
- Live real-time match data ingestion during games.
- Full deployment to production infrastructure (focus is on architecture and ML pipeline first).
